## <a name="version-française"></a>🇫🇷 Version Française

### Description
Un système complet de gestion bancaire développé en langage C.

### Fonctionnalités
- Gestion des comptes (création, modification, suppression)
- Transactions (dépôt, retrait, virement)
- Persistance des données à travers la manipulation de fichiers
- Chiffrement XOR pour la sécurité des données

### Concepts abordés
- Listes chaînées (gestion dynamique de la mémoire)
- Architecture modulaire
- Manipulation de fichiers (I/O)
- Logique algorithmique

### Compétences acquises
- Conception de systèmes en C
- Implémentation de structures de données dans une application réelle
- Gestion de logiques complexes et traitement des cas particuliers
